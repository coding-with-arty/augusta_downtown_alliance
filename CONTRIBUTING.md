# Contributing Guide

Thank you for helping improve the Augusta Downtown Alliance website.

## Ways to Contribute
- Submit an Issue (recommended)
- Comment on existing Issues
- Submit a Pull Request

## Quick Start
1. Go to the repository
2. Click "Issues" → "New Issue"
3. Fill out the form

## Pull Requests
1. Fork the repo
2. Edit files
3. Commit changes
4. Open Pull Request

All submissions are reviewed before going live.
